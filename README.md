<h1>API engine</h1>

<p>Locomotive for all network work.</p>
<p>By default works using queue and have caching option.</p>
<p>Caching could be set using your own CacheContainer class, which is present in package</p>

<p>IMPORTANT!</p>
<p>You have to use startQueue() method to make API work either you will error that Queue is not set</p>
